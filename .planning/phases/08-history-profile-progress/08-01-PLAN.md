<objective>
Build candidate history tracking, session logs, user profile management, and progress analytics matching the Figma Make design system.
</objective>

<execution_context>
- Sessions model stores userId, status, score, createdAt, role, interviewType, answers.
- User model stores name, email, college, targetRole, avatarUrl, createdAt.
</execution_context>

<tasks>
<task id="1" type="auto">
  <name>Backend — History & Profile API Endpoints</name>
  <files>
    - backend/controllers/sessionController.js
    - backend/routes/sessions.js
    - backend/controllers/authController.js
    - backend/routes/auth.js
  </files>
  <action>
    1. Update `backend/controllers/sessionController.js` to add `getUserHistory(req, res)`:
       - Fetch all sessions for `req.user._id` sorted by `createdAt` descending.
       - Include summary stats: totalSessions, completedCount, averageScore, latestReadinessLevel.
       - Return 200 OK with `{ sessions, stats }`.
    2. Add `GET /api/sessions/history` route in `backend/routes/sessions.js` protected by `protect`.
    3. Update `backend/controllers/authController.js` to add `updateProfile(req, res)`:
       - Update name, college, targetRole, and optional password.
       - Return 200 OK with updated user profile.
    4. Add `PUT /api/auth/profile` route in `backend/routes/auth.js` protected by `protect`.
  </action>
  <acceptance_criteria>
    - `GET /api/sessions/history` returns 200 OK with user session history & overall stats.
    - `PUT /api/auth/profile` allows users to update their profile info and returns 200 OK.
  </acceptance_criteria>
</task>
