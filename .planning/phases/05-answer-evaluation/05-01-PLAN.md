<objective>
Build an intelligent, non-hardcoded answer evaluation engine in `nlp-service` that compares Question + Evaluation Criteria + User Transcript to produce structured quality scores (`relevanceScore`, `correctnessScore`, `completenessScore`, `communicationScore`, `overallScore`, `feedback`, `strengths`, `improvements`).
</objective>

<execution_context>
- Transcribed candidate answers are submitted to `nlp-service` at `http://127.0.0.1:8003/analyze` or `POST /api/analysis/evaluate`.
- Questions can be technical or behavioral; evaluation logic adapts to question context.
- Output stores structured scores and feedback arrays on `Session.answers[i].nlpAnalysis`.
</execution_context>

         - Dynamic scoring without static hardcoded numbers.
