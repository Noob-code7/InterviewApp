Build the candidate performance report pipeline: backend score aggregation & API, report generation microservice, and premium frontend ReportPage matching Figma Make styling.

<tasks>
<task id="1" type="auto">
  <name>Backend — Report Controller, Aggregation Engine, & Routes</name>
  <files>
    - backend/controllers/reportController.js
    - backend/routes/reports.js
    - backend/app.js
  </files>
  <action>
    1. Create `backend/controllers/reportController.js` with `getReport(req, res)`:
       - Retrieve session by `req.params.sessionId` and verify ownership (`req.user._id`).
       - Compute overall score:
         - Face score (attention & confidence average)
         - Voice score (fluency & clarity average)
         - Answer NLP score (relevance & completeness average)
         - Writing score (structure & grammar average from writingAnalysis)
       - Calculate overallScore = (face + voice + answer + writing) / 4.
       - Determine readinessLevel ('market-ready' for >=85, 'high' for >=75, 'medium' for >=60, else 'low').
       - Persist calculated scores on Session model if not already set.
       - Return 200 OK with full session and aggregated report JSON.
    2. Create `backend/routes/reports.js` mounted at `/api/reports` with `GET /:sessionId` protected by `protect`.
    3. Mount `app.use('/api/reports', reportRoutes)` in `backend/app.js`.
  </action>
  <acceptance_criteria>
    - `GET /api/reports/:sessionId` returns 200 OK with session report data.
    - Aggregated overallScore and readinessLevel are properly computed and returned.
  </acceptance_criteria>
</task>
